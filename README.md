# Help Center Chat Interface

A wireframe prototype for a Help Center page with an interactive chat assistant popup.

## Features

- Help Center page with search, autocomplete, and topic cards
- Chat popup triggered by a floating action button (FAB)
- Fullscreen expand mode with hash-based routing (`#/home`, `#/conversation`)
- Browser back/forward navigation between home and conversation views
- Responsive layout: tablet (≤768px) and mobile (≤480px)
- Phosphor Icons, Montserrat font

## Stack

- React 18 + TypeScript
- Vite
- @phosphor-icons/react
- Tailwind CSS (base reset only)

## Getting started

```bash
npm install
npm run dev
```
